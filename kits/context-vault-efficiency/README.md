# Context Vault & Token Efficiency Kit

Anti-rot knowledge architecture and model-tiering optimization kit for high-efficiency agent fleets.

## Core Capabilities

- **Karpathy Anti-Rot Synthesis**: Continuously synthesizes ephemeral execution state into structured living Markdown runbooks.
- **Context Compaction Pipeline**: Targeted retrieval and filtering to prevent raw transcript token inflation.
- **Cheapest Adequate Model Tiering**: Classifies tasks into Economy, Balanced, and Premium tiers to preserve valuable quota.
- **Empirical Outcome Ledger**: Tracks task token usage, durations, costs, and success rates for continuous routing optimization.

## Pipeline Flow

```text
Incoming Task --> Targeted Search --> Living Doc Compaction --> Cheapest Adequate Tier Selection --> Audited Execution --> Outcome Ledger
```
