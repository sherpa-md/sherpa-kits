## Add your project

Two paths are available:

- **GitHub pull request:** Copy [`PROJECT_TEMPLATE.md`](./PROJECT_TEMPLATE.md) into a new project folder and submit it.
- **Guided submission:** Open a **Share a community project** issue and provide the requested links, screenshots, testing notes, and credit.

Each project gets its own folder so its files, screenshots, history, and attribution stay together.

## Ground rules

- Share only work you have permission to publish.
- Never include API keys, tokens, private URLs, private IPs, customer data, employer data, or unredacted account screenshots.
- State what was tested and what is still experimental.
- Link the Sherpa Kit that inspired the work.
- Credit every builder and upstream project.
- Do not present a community project as an official or verified SherpaMD release.

Canonical instructions remain in [`kits/`](../kits/). Community builds live here so experimentation cannot overwrite the reference kit.
