# Token Piggy Bank Community Builds

Different people will visualize and govern model quotas differently. This showcase keeps those versions together without choosing one winner or replacing the canonical kit.

## Canonical starting points

- [Token Piggy Bank kit](../../kits/token-piggy-bank/)
- [Shareable TokenPiggyBank.sherpa.md](../../handoffs/TokenPiggyBank.sherpa.md)

## Published builds

No community build has been imported yet. The first contributed version will be listed here with its builder credit, screenshot, tested environment, and source/demo links.

## Add a version

Create:

```text
projects/token-piggy-bank/<project-slug>/
├── README.md
└── screenshots/
```

Start by copying [`../PROJECT_TEMPLATE.md`](../PROJECT_TEMPLATE.md). A working app may live in this repository or link to its own repository; the showcase README must still explain what it does and how it differs.

For someone who does not want to prepare a pull request, open a **Share a community project** issue and select **Token Piggy Bank**. A maintainer can help place the supplied materials correctly.

## Acceptance checklist

- Builder permission and preferred credit are recorded.
- The implementation links back to the canonical Token Piggy Bank kit.
- Screenshots are sanitized.
- Tested and untested behavior are clearly separated.
- Setup instructions do not expose secrets or private infrastructure.
- The project is presented as a community build, not an official verified release.
