# Approved Private Data Analyst

Build a permission-aware analysis system that lets employees ask useful questions across private company documents and structured data without copying that data into an unapproved AI service.

The system combines tenant-approved LLM access, identity-bound retrieval, structured query tools, citations, claim-state labels, audit receipts, and approval gates for exports or actions. For a Microsoft 365 organization, Microsoft Copilot and tenant-governed Microsoft services are a concrete implementation path; another company may substitute its formally approved equivalent.
