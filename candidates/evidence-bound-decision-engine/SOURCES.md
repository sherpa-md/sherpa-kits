# Sources and design inferences

- [W3C PROV-O](https://www.w3.org/TR/prov-o/) — interoperable provenance model used for claim/source/activity/agent relationships.
- [NIST AI 600-1](https://doi.org/10.6028/NIST.AI.600-1) — generative-AI risk profile supporting structured governance and testing.
- [OWASP LLM01:2025 Prompt Injection](https://genai.owasp.org/llmrisk/llm01-prompt-injection/) — supports treating retrieved material as untrusted and requiring least privilege, validation, and human approval.

## Inferences

- Citation presence is not evidence quality; the system must also evaluate whether the source actually supports the atomic claim.
- Sensitivity analysis is necessary because a single weighted score can conceal fragile assumptions and value judgments.
