# Validation

## Acceptance cases

| Case | Pass condition |
|---|---|
| Revision leakage | Only the version available at estimate time is evaluated |
| Scope change | Approved change is separated from original estimation error |
| Incomplete actual | Case is censored, not treated as final |
| Duplicate project | Near-duplicate cannot cross train/evaluation split |
| Small cohort | System abstains or widens uncertainty; no precise rule is published |
| Arithmetic | Independent code reproduces every metric |
| Prospective test | Adjustment is evaluated on future held-out cases |
| Data boundary | Proprietary rows never leave the approved company environment |

## Metrics

- Signed bias, median absolute error, interval coverage, and error by cohort.
- Prospective improvement relative to unchanged baseline.
- Adjustment-card adoption, override, and retirement rates.
- Reviewer acceptance of explanation hypotheses.
