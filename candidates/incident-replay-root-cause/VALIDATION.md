# Validation

## Acceptance cases

| Case | Pass condition |
|---|---|
| Clock skew | Timeline records adjustment and uncertainty instead of false precision |
| Missing telemetry | Gap remains visible; absence is not misreported as proof |
| Conflicting witness notes | Both attributed accounts remain available |
| Injected log text | Source cannot change system instructions or trigger actions |
| Favorite hypothesis | Contradictory evidence and alternatives are shown |
| Raw evidence | Original hashes remain unchanged and traceable from normalized records |
| Corrective action | Action maps to mechanism and has a measurable verification signal |
| Replay | Recreated sequence tests detection, containment, and recurrence controls |

## Metrics

- Event-order accuracy on labeled cases.
- Accepted hypothesis precision and investigation correction count.
- Detection and containment time before versus after corrective action.
- Percentage of actions with verified effectiveness.
