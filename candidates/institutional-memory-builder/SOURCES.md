# Sources and design inferences

- [W3C PROV-O](https://www.w3.org/TR/prov-o/) — provenance relationships for entities, activities, agents, primary sources, derivations, revisions, and invalidations.
- [Microsoft: Semantic indexing for Copilot](https://learn.microsoft.com/en-us/microsoftsearch/semantic-index-for-copilot) — primary documentation for semantic grounding and permission-aware result surfacing in Microsoft 365.
- [Microsoft: Enterprise data protection in Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/enterprise-data-protection) — primary documentation for inherited identity, permission, sensitivity, retention, and audit controls.

## Inferences

- A useful memory needs authority, scope, time, ownership, and contradiction handling in addition to embeddings.
- Permission preservation must apply to chunks, citations, caches, summaries, and generated knowledge objects—not just original files.
