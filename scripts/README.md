# Maintainer Scripts

These files maintain the repository. Visitors looking for a Sherpa file should use **[handoffs/](../handoffs/)**.

| Script | Purpose |
|---|---|
| `validate_sherpa.py` | Validates SherpaMD front matter and common secret patterns |
| `build-handoff-bundle.sh` | Creates a requested bundle of the individual files in `handoffs/` |

The bundle script is manual. Do not run it automatically; use it only when somebody specifically requests all handoffs together.
