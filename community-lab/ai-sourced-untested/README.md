# Community Lab: 100 AI Problem Seeds

> **AI-GENERATED · UNTESTED · NOT SHERPAMD-VERIFIED · NOT FINISHED SOLUTIONS**

These files were generated quickly to identify common problems people encounter while using AI. Inspection showed that the current contents are repetitive scaffolds—not complete SherpaMD kits.

## What this collection is for

Pick a problem seed, reproduce the problem safely, research why it happens, and replace the generic scaffold with a specific workflow that actually solves it.

A contribution should include:

- the exact problem and who experiences it;
- evidence or direct source links showing it is real;
- a concrete copy/paste workflow with fill-in fields;
- a worked example;
- expected and actual results;
- privacy and safety notes;
- a test report using `TEST-RESULT-TEMPLATE.md`.

## Status

Every file remains **AI-sourced and untested** until a human tests it. Nothing here belongs in the verified SherpaMD catalog yet.

Never submit passwords, API keys, proprietary data, personal information, or unsanitized test inputs.
