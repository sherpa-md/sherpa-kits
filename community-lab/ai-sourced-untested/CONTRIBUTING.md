# Contributing a Real Solution

Choose one `.sherpa.md` problem seed and improve that file on this branch.

A submission must:

1. Link to at least two direct examples of people encountering the problem.
2. Replace generic text with a problem-specific workflow.
3. Include a reusable prompt with clearly marked fill-in fields.
4. Include one sanitized worked example.
5. Record the model/provider and actual test result.
6. Complete `TEST-RESULT-TEMPLATE.md`.
7. Remove no AI-sourced or untested warning until human testing is documented.
8. Contain no secrets, personal data, proprietary material, or fabricated citations.

Promotion into the verified SherpaMD catalog requires human review and a reproducible passing test.
